# Security policy
Phase 0 is a public metadata foundation, not a multi-tenant production service.
Do not upload personal data or use it to store secrets. No upload or login endpoints exist.
For vulnerabilities, use the repository Security Advisories private reporting feature if enabled;
otherwise contact the maintainer through the GitHub profile without sending exploit secrets publicly.
No response SLA is promised. See docs/security/THREAT_MODEL.md for current and planned controls.
