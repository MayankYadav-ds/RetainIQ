# Local model registry and inference boundary

The benchmark and holdout have separate commands. The data root contains ignored ml/experiments, ml/models and ml/evaluations directories. Each experiment binds the protocol, dataset, view, dependencies and quick/full mode. Aggregate evidence is separate from private OOF rows and fold role membership. Freeze binds the selected configuration, preprocessing fingerprint and parameters, calibration, threshold, source range and exact artifact hash. Directory publication uses same-filesystem staging and rename. Restore validates the model ID, SHA, dependency versions, feature order, artifact size, finite scaling and calibration parameters before inference.

Scikit-learn models serialize with skops. Loading uses a fixed reviewed allowlist for the five HistGradientBoosting internal types; other supported scikit-learn families must report no additional types. XGBoost uses native UBJSON and LightGBM native model text. No pickle or joblib loading code is used. Exact versions remain pinned. Each artifact is trusted local operator output. Checksums detect accidental corruption; they are not signatures. Never place uploads or unreviewed models in the data root. Keep the local store access-controlled. The reference backend runs on a loopback interface.

One holdout ledger is keyed by dataset and checksum. Creating the exclusive start marker authorizes one label-reading run. The receipt binds the model freeze, local prediction checksum and evaluation timestamp. An existing receipt is verified and returned. If interrupted after the marker is created and before publication, automatic retry is blocked. Preserve evidence and audit the access before any correction. Activity by an unrestricted local administrator is outside this control.

Set RETAINIQ_ACTIVE_MODEL to a verified evaluated model ID to opt into inference. Remove the variable to disable inference or set it to a previously evaluated compatible model and restart. A fresh install without a model starts normally. Production mode leaves the local demonstration routes unavailable for prediction. There is no upload, activation, retraining or artifact download HTTP interface.
