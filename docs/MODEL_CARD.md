# Histogram gradient boosting model card

Frozen model 2234d0279bb9bd18d77c27b3. Intended use is local scientific review of first-nine-month features predicting the UCI month-twelve churn state. Operational outreach, monetary risk assessment, causal interventions, exact daily horizons, fairness claims and production deployment require separate evidence.

The training source was the 2,480 eligible UCI development observations after the frozen eight-feature overlap quarantine. Five frozen grouped outer folds provided development-informed evidence. Final evaluation used the original 630 held-out observations. The model uses FS01 plus deterministic tariff encoding. It excludes Status, Customer Value, charge band, Age, Age Group, ordinal and target. Final configuration is max_iter=100, max_leaf_nodes=15, class_weight=balanced, early_stopping disabled. The final policy uses sigmoid calibration and threshold 0.28. See [selection protocol](ML_EXPERIMENT_PROTOCOL.md), [benchmark](MODEL_BENCHMARK.md) and [final evidence](FINAL_EVALUATION.md).

The source lacks verified customer identifiers, calendar timestamps, censoring, reliable time horizons and intervention assignments. Performance could differ on new cohorts, entities, coding conventions and base rates. Fairness across demographic groups has not been evaluated. Missing, extra and unsupported categorical input is rejected. Valid out-of-range data receives a marginal warning. Model deployment needs authenticated access, prospective calibration and drift monitoring, observed outcome reconciliation and data retention review. Untrusted model uploads and private score exports are prohibited.

For Phase 4, the frozen preprocessor and ordered encoded FS01 output are available. Histogram gradient boosting explanations should target the underlying additive decision margin (log-odds) where the explainer supports the exact pinned estimator. The calibration transform operates on the model probability and individual SHAP contributions cannot be calibrated independently. Verify SHAP compatibility and additivity before displaying explanations. Keep any authorized background sample development-only and local.
